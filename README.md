# Interactive Solar System

An interactive, sprite-based solar system model built with HTML, CSS, and JavaScript. Explore the planets, adjust simulation speed, and pan or zoom around the model.

## Run locally

Serve this project directory over HTTP and open `index.html`. The application uses JavaScript modules, which browsers do not load reliably from a `file://` URL.

## Controls

- Hover over, focus, or select an object to read its overview.
- Drag to pan around the model.
- Use the mouse wheel to zoom.
- Adjust the time slider to change the simulation speed or pause motion.

## Project layout

```text
assets/
  fonts/
  sprites/
css/
js/
  controls/
  data/
  render/
index.html
```

The Jersey 15 font and its license are in [assets/fonts](./assets/fonts/).
